🔌 Setup (one-time)

  • Click Download install.bat — that's the only file you need
  • Right-click it → Properties → check "Unblock" → OK (Windows security step)
  • Double-click install.bat — it asks for Administrator, then downloads bridge.py, installs Python only if it's missing, installs the packages, and starts the bridge for you
  • Click Start Camera — steering works!

Prefer to grab bridge.py yourself? Download bridge.py too — install.bat will skip its own download if it finds one already sitting next to it.

💡 How It Works

The browser does face tracking via MediaPipe. It sends left/right/release commands over WebSocket to bridge.py, which presses real keyboard keys system-wide via pynput.

🎯 Tips for Accuracy

  • Face well-lit, no strong backlight
  • ~50–80 cm from camera
  • Sit upright, tilt naturally
  • Camera at eye level is best
